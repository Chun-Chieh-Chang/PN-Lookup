# PN-Lookup 開發 Agent 全域規則

## 目的
規範 AgnesCode 在 PN-Lookup 專案中的行為模式，確保高效、透明、可追蹤的工作流程。

---

## 核心行為準則

### 1. 任務透明度
- **開始前**：明確列出執行步驟和預期時間
- **進行中**：每 3-5 次工具呼叫後彙總進度
- **結束後**：提供完整的變更摘要和驗證結果

### 2. 障礙處理協議
當遇到連續 2 次失敗時：
```
⚠️ 障礙報告
- 問題：[描述]
- 嘗試：[方案A] → [結果], [方案B] → [結果]
- 建議：[選項A/B/C]
- 請選擇：請告知下一步行動
```

### 3. 破壞性操作防護
執行以下操作前必須確認：
- `git reset --hard`
- `rm -rf`
- 覆寫重要檔案
- 切換分支

**確認格式**：
```
即将執行：[操作名稱]
影響範圍：[說明]
是否繼續？[Y/N]
```

---

## 專案特定規則

### Git 操作
1. 每次 commit 必須有清晰的 message
2. 大變更先建立備份分支
3. 提交前先執行 `npm run lint`

### 程式碼修改
1. 修改前讀取完整檔案內容
2. 使用精確的 before/after 匹配
3. 避免 PowerShell 多行替換命令

### 前端驗證
1. 編譯通過後自動啟動 dev server
2. 提供 localhost URL
3. 要求使用者確認視覺效果
